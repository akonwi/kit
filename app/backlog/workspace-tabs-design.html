Proposed behavioral contract

OpenEvery opened tab remains until explicitly closed. Reopening an existing identity selects it instead of duplicating it.
ActivityOne singleton Activity tab follows the currently selected turn. Changing turns updates that tab in place.
CloseThe explicit × removes a tab immediately. No default terminal chord and no dirty confirmation; a keymap command remains configurable.
ResizeCrossing the breakpoint reprojects the same mounted surfaces; it does not reopen, close, or reset them.
