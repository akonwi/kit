State contract

PROBING ├─ credential + model ───────────────► READY ├─ no usable credential ─────────────► GATE └─ daemon failure ───────────────────► RETRY / DIAGNOSTICS GATE ── enter ──► PROVIDER ├─ device OAuth ─► WAIT ──────────┐ ├─ browser OAuth ─► CALLBACK ─────┼─► GUARDED SAVE ─► READY └─ API key ───────► VALIDATE ─────┘ WAIT ├─ esc ─► cancel poll ─► PROVIDER └─ expiry / denial ─────► PROVIDER + reason GUARDED SAVE ├─ concurrent auth change ─► PROVIDER + retry └─ saved, no model ─────────► DEGRADED GATE DEGRADED GATE └─ connect another / re-check / quit
