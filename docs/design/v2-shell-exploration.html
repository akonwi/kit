Kit v2 shell direction

A comparison between the installed terminal UI and a viewport-native v2 direction: one attached session per client, terminal-native multiplexing, and session-local subagent oversight.

First attach

The direction preserves the calm entry state. Startup attaches or resumes one session according to CLI policy; other sessions are not promoted into shell chrome.

Same IA

Subagents remains a normal workspace tab at narrow widths.

Session-local

Counts describe this session's agents and conversations only.

Open

Enter creates or focuses the selected agent's retained activity tab.

Candidate principles

preserve the calm · expose only relevant scope

Quiet continuity

The daemon makes detach and terminal multiplexing safe without permanent chrome.

Session-local oversight

Subagent roster and activity tabs live inside their owning session's workspace.

Narrative vs evidence

Transcript tells the story. Activity holds raw execution detail.

One ranked palette

Ctrl+P finds actions and places in one relevance-ranked surface.

Progressive density

Idle is calm. Running adds actionable footer status—not decorative telemetry.

One surface owner

Shell, host, and pane each own one layer of structure—never duplicate chrome.

Honest text

Ellipsize truncation, label overflow, and name ambiguous metadata.

Input parity

Every pointer action has a visible keyboard path and focus state.

One responsive IA

Splits become tabs or drawers without changing concepts or losing state.

Explicit interruption

Abort, detach, cancel, clear, queue, and daemon stop never blur together.

Port faithfully

  • Semantic terminal-derived theme contract
  • Workspace pane registry and retained state
  • Keymap-derived hints and user rebinding
  • Transcript-first progressive disclosure
  • Responsive split-to-tabs behavior

Deliberately evolve

  • Viewport-native root boundary
  • One ranked, content-hugging universal palette
  • Labeled overflow and unambiguous metadata
  • Explicit detach safety for the attached session
  • Main-compatible Subagents roster and retained activity tabs
