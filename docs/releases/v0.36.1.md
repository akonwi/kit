Kit 0.36.1 improves subagent model selection and restores convenient message
recall in the native composer.

## What's changed

- **Subagent model selection:** a bare model ID in an agent definition now selects
  the first matching available provider in registration order. Explicit
  `provider/model` selectors still target only that provider. If the requested
  model cannot be resolved, Kit retains the existing fallback to the parent’s
  active configuration with a warning.
- **Message history:** press **Up** in an empty composer, when no queued follow-ups
  take precedence, to browse recent persisted user messages newest-first. Filter
  the list and select a message to insert its text without submitting it. The
  picker loads up to 500 messages; it does not restore attachments or annotations.
- **Composer positioning:** message and bash history pickers are anchored to the
  composer, like mention pickers.

## Upgrade and use

```sh
brew update
brew upgrade akonwi/tap/kit
kit -v
kit
```

Homebrew availability follows the formula update. Alternatively, extract the
matching release archive and install its single `kit` executable on your PATH.
Expected version: `0.36.1`. Close old clients and, when interrupting active work
is acceptable, run `kit server restart` to use the updated server before
reopening Kit. No settings, credentials, or session-data conversion is required
when upgrading from 0.36.0.

To pin a subagent to Codex rather than letting provider availability choose:

```yaml
model: openai-codex/gpt-5.6-sol
```

See the [0.36.1 migration notes](https://github.com/akonwi/kit/blob/v0.36.1/docs/releases/v0.36.1-migration.md)
for user and assistant guidance. Upgrading from 0.35.x still requires the
[0.36.0 migration guidance](https://github.com/akonwi/kit/blob/v0.36.0/docs/releases/v0.36.0-migration.md).

## Compatibility and verification

Platform requirements are unchanged: macOS 14+ on Apple Silicon or Intel, and
Linux arm64/amd64 with the Ubuntu 24.04/glibc 2.39 baseline. Windows and npm
installation are unsupported. Archives contain only the native executable;
plugins and MCP servers may require their own runtimes.

Local formatting, build, vet, full Go tests, race tests, and workflow lint passed.
Authenticated provider/MCP end-to-end coverage and installed Linux/Intel upgrade
verification remain incomplete. This patch does not add plugin message submission,
plugin footer clicks, or other previously unsupported plugin APIs.
