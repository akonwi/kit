Kit 0.36.2 fixes discovery of symlinked context sources, making it easier to keep
shared instructions, skills, and prompts in a separate configuration repository.

## What's changed

- Context files such as `AGENTS.md` can be symlinks to readable regular files.
  Context aliases resolving to the same path are deduplicated.
- Skill discovery follows symlinked search directories, nested skill directories,
  and `SKILL.md` files. Revisited resolved directories are skipped to avoid loops.
- Prompt discovery accepts symlinked prompt directories and Markdown files.
- Existing discovery limits and regular-file checks remain in place. Broken or
  invalid links are omitted; context and skill discovery report diagnostics.

## Upgrade and get started

```sh
brew update
brew upgrade akonwi/tap/kit
kit -v
kit
```

Homebrew availability follows the formula update. For manual installation,
extract the matching release archive and put its single `kit` executable on
PATH. Expected version: `0.36.2`. Close old clients and run `kit server restart`
when interrupting active work is acceptable, then reopen Kit.

No configuration or session-data conversion is required from 0.36.x. Symlinked
sources that were previously skipped can now contribute instructions and prompts;
review their targets before reloading. See the
[0.36.2 migration guide](https://github.com/akonwi/kit/blob/v0.36.2/docs/releases/v0.36.2-migration.md).
For upgrades from 0.35.x, also follow the
[0.36.0 migration guide](https://github.com/akonwi/kit/blob/v0.36.0/docs/releases/v0.36.0-migration.md).

## Compatibility and verification

Platform requirements are unchanged: macOS 14+ on Apple Silicon or Intel, and
Linux arm64/amd64 with the Ubuntu 24.04/glibc 2.39 baseline. Windows and npm
installation are unsupported. Plugins and MCP servers may need their own runtimes.

Local formatting, build, vet, full Go tests, race tests, and workflow lint passed.
Authenticated provider/MCP end-to-end coverage, installed Linux/Intel upgrade
verification, and exact C/SDK toolchain pinning remain incomplete. This release
does not add plugin-initiated model turns; that capability is tracked in the backlog.
