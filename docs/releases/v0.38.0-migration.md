# Migrating to Kit 0.38.0

Use source and archives at **tag v0.38.0** when published. Check your installed binary and running server separately; do not put credentials in prompts, notes, or commits.

## From 0.37.x (protocol 40)

1. Inspect `command -v kit`, `kit version`, and `kit server status`. Let active turns, child tasks, and integrations settle. Back up native session data with the daemon stopped if you need rollback; do not edit SQLite files while it runs.
2. Install the new CLI through `brew update && brew upgrade akonwi/tap/kit` after the formula is published, or extract the matching `kit_v0.38.0_<platform>.tar.gz` archive (containing only `kit`) onto PATH. Check `kit version` reports 0.38.0. Replacing the binary does **not** replace the running daemon.
3. Protocol 41 changes the subagent mailbox snapshot shape. A 0.38.0 client will not attach to a protocol-40 daemon; it leaves the daemon running. Once work is settled and interruption is acceptable, run `kit server restart` with the new binary, then `kit server status`. If no daemon is running, start Kit normally. Reopen other clients on the new version. macOS app 0.1.0 uses protocol 40; update the app to 0.1.1 before reconnecting to the protocol-41 server. Do not restart the server merely to satisfy an incompatible old client.
4. Check saved sessions, subagent conversations and pending requests, provider login, and any MCP/plugin integrations you rely on. The server applies new subagent-request and parent-delivery database migrations on startup. Do not manually edit or downgrade that database: the protocol compatibility policy does not promise database downgrade safety. Existing configuration does not require a format conversion for this release; reauthenticate only if your integrations need it.

Parent agents use the `subagent` tool with `action: ask` for an explicit answer, `action: send` for a receipt and later response, and `action: inspect_request` to recover request state. Children use `subagent_send` to request a configured sibling, `subagent_inbox` and `subagent_inspect` to inspect pending work, and `subagent_reply` to answer an addressed request. Simply completing a child task is not a reply. Children cannot start, cancel, or dismiss their sibling's lifecycle directly. Update prompts or plugins that previously treated a child task's terminal output as an explicit response.

Stable versions >= 0.38.0 with protocol 41 can attach across release labels. The 0.37.x protocol-40 promise applies only to protocol-40 peers. Development/prerelease skew and database downgrades remain unverified. If you must retain a protocol-40 daemon, continue with matching 0.37.x clients and app 0.1.0 instead of upgrading one client in isolation.

## From 0.36.x or earlier

Follow the [0.36.0](v0.36.0-migration.md) and [0.37.0](v0.37.0-migration.md) guides first, including any applicable 0.36.x maintenance adjustments. Native Kit does not import legacy runtime sessions or credential internals.
