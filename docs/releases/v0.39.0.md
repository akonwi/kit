# Kit 0.39.0

This release publishes protocol 42 contract slices and hardens client/server event records. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- The session API contract now covers scratchpads, VCS status and observation streams, plugin commands, and live plugin toast streams.
- Plugin toasts use server-sent events; plugin command failures use typed contract errors.
- Transcript content and session events are internally represented as discriminated unions while retaining their flat JSON wire records. Invalid cross-variant event fields are rejected during decoding.
- The native TUI includes palette and inline-picker improvements.
- Fixes include compaction handling for managed-effort models and safer subagent frontmatter diagnostics.

## Upgrade and get started

```sh
brew update && brew upgrade akonwi/tap/kit
kit version
kit server status
```

For manual installation, download `kit_v0.39.0_<platform>.tar.gz`, extract its single `kit` executable onto PATH, and verify `kit version`. Supported archives are `darwin_arm64`, `darwin_amd64`, `linux_arm64`, and `linux_amd64`.

Protocol 42 is not compatible with protocol-41 clients or daemons. Let active work settle before explicitly restarting the daemon with the new binary, then update attached CLI clients. The CLI leaves an incompatible running daemon untouched. Back up state before operational changes and do not attempt a database downgrade.

## Compatibility and limitations

Canonical stable 0.39.0-or-later releases that retain protocol 42 may share a protocol-42 daemon. Development builds and prerelease labels are outside that compatibility promise. macOS CLI archives require macOS 14+; Linux archives use Ubuntu 24.04 (glibc 2.39 baseline) and are not fully static. Windows and npm distribution are unsupported.

Open backlog work remains, including the turns/events/transcript API slice and resumable event streams. The CLI archives do not contain the separately distributed macOS app. Plugins and MCP integrations may require their own runtimes.
