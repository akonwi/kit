# Kit 0.40.0

This release adds a public Go client SDK, provider-aware image handling, prompt-cache controls, and per-conversation subagent configuration. It also advances the session API to protocol 43. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- Kit now publishes a typed, stateful Go client at `github.com/akonwi/kit/api`. It supports local discovery or explicit targets, compatibility and authentication checks, immutable session attachments, reconnecting event streams, and typed public errors without starting or replacing a daemon.
- The OpenAPI contract now catalogs the complete session operation surface, including turns, transcripts and resumable events, session lifecycle, diffs, annotations, workspaces, attachments, bash, subagents, plugins, and server operations. CI compares contract changes with the latest stable release and requires a protocol bump for breaking changes.
- Images are prepared for each provider and model without rewriting durable history. Kit applies orientation, bounded resizing, deterministic re-encoding, and provider-specific limits; unsupported historical images become model-visible placeholders instead of preventing later requests or model switches. Anthropic models can now receive image attachments and `inspect_image` results.
- Anthropic prompt caching is enabled for Anthropic-hosted requests, and supported public OpenAI Responses models receive reviewed cache controls. Set `promptCacheRetention` to `"short"` (the default) or `"long"` in `$KIT_HOME/settings.json`; see `docs/features/prompt-caching.md` for provider-specific behavior and pricing.
- Durable subagent conversations can use a model and thinking level independent of their parent. Thinking changes apply to the next provider request; model changes require the child to have no active or queued work and may compact its stored context first.
- Prompt commands submitted while a session is busy can be queued as follow-ups while retaining their command form in previews.
- Long subagent transcripts are paged like parent transcripts. TUI fixes keep subagent conversations pinned to the latest response, enable mouse scrolling in the scratchpad, and give file paths the available picker width.

## Upgrade and get started

```sh
brew update && brew upgrade akonwi/tap/kit
kit server restart
```
