# Kit 0.42.0

This release lets plugins submit attributed messages that start turns, discovers project Claude Code commands in the command palette, and preserves prompt-command invocations in session history. It also fixes plugin message summaries in the TUI. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `e4f17a42` — feat(plugins): let plugins submit session messages (#63)
- `7f6499e9` — fix(tui): show plugin message summaries as plain text
- `d74ad597` — feat(prompts): discover Claude Code project commands and record prompt command invocations (#64)

## Upgrade guide

Kit 0.42.0 advances the session API from protocol 44 to protocol 45. Protocol-44 clients and daemons are not compatible with this release. Let active work settle, upgrade Kit, and then explicitly restart the daemon:

```sh
brew update && brew upgrade akonwi/tap/kit
kit server restart
kit version
kit server status
```

Update every attached CLI or Go client to a protocol-45-compatible version. The public Go client contract adds the `plugin.message.added` session event, the `promptCommand` transcript content kind, and the `claude_project` prompt-command source. Clients that exhaustively handle these unions must add the new variants.

For manual installation, download `kit_v0.42.0_<platform>.tar.gz`, extract its single `kit` executable onto PATH, and verify `kit version`. Back up state before operational changes and do not attempt a database downgrade.

## Compatibility and limitations

Canonical stable 0.42.0-or-later releases that retain protocol 45 may share a protocol-45 daemon. Development builds and prerelease labels are outside that compatibility promise. The published macOS app (0.1.2) uses an earlier protocol and is not compatible with this daemon; an updated app is released separately.

Project Claude Code commands are read from the top level of `<session-cwd>/.claude/commands/` by default. Run **reload** after changing command files or the session cwd. Set `readClaudeConfigs` to `false` in `$KIT_HOME/settings.json` to disable that discovery. Kit does not read personal or nested Claude Code commands, and it treats command substitutions and file references as literal text.

Plugin-submitted turns start only when the owning session is idle; Kit does not queue a rejected submission or retry it. Autonomous plugin, subagent, and peer turn chains have no fixed turn-count limit, so integrations that start repeated turns must provide their own stopping policy. Plugins and MCP integrations may require their own runtimes.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
