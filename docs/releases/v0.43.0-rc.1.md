# Kit 0.43.0-rc.1

This is a release candidate for Kit 0.43.0. It is published as a prerelease to test the release process and the new terminal client before 0.43.0 is promoted. The Homebrew formula is not updated for candidates. The native macOS app is released separately and is not included in CLI archives.

Kit's terminal client is rewritten in [Ard](https://github.com/akonwi/ard) with the [Cooper](https://github.com/akonwi/cooper) terminal UI toolkit, and the `kit` executable is now built from it. The client aims to look and behave like the previous one, including the transcript, tool activity, composer, interaction dock, command palette, workspace tabs, subagents, and session explorer. The commands, flags, help, and exit codes are unchanged.

## Trying the candidate

Download `kit_v0.43.0-rc.1_<platform>.tar.gz`, extract its single `kit` executable somewhere outside your PATH, and check its version:

```sh
./kit version   # kit 0.43.0-rc.1 (<commit>)
```

A candidate does not attach to a running daemon of another version. Either try it with a separate Kit home, which needs its own provider login:

```sh
KIT_HOME="$(mktemp -d)" ./kit
```

or let active work settle, stop your stable daemon, try the candidate, and then restart the stable daemon with your installed `kit`. The candidate does not change Kit's stored data format, so 0.42.0 can reopen the same Kit home afterward:

```sh
kit server stop
./kit
./kit server stop
kit server start
```

Please report anything that behaves differently from Kit 0.42.0.

## Compatibility and limitations

The session protocol is still 45. Release candidates are outside the stable-release compatibility promise: a candidate shares a daemon only with the same build.

Known differences from the previous terminal client:

- Centered content of odd width can sit one cell to the right.
- The signed-out **Connect a provider** button uses the accent color.
- `kit sessions` lists sessions before its picker opens and sizes the picker to them once.

macOS CLI archives require macOS 14+; Linux archives use Ubuntu 24.04 (glibc 2.39 baseline) and are not fully static. Windows and npm distribution are unsupported.
