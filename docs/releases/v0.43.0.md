# Kit 0.43.0

Kit's terminal client is rewritten in [Ard](https://github.com/akonwi/ard) with the [Cooper](https://github.com/akonwi/cooper) terminal UI toolkit, and the `kit` executable is now built from it. The client looks and behaves like the previous one, including the transcript, tool activity, composer, interaction dock, command palette, workspace tabs, subagents, and session explorer, and adds the improvements listed below. The commands, flags, help, and exit codes are unchanged. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `26c94b1d` — feat(cli): Ard + Cooper terminal client (#74)
  - The interaction dock is a docked panel at its natural height. Guided questions show a trail of answered, current, and remaining steps, and Shift+Tab returns to an earlier answer.
  - Bash mode turns the composer into a docked Bash panel, as in the macOS app, with an **In context** / **Not in context** switch. Finished `!` commands keep their place in the transcript after reattaching.
  - Staged attachments are chips that wrap, with an upload spinner and a close button.
  - Images preview inline: click an image attachment to expand it, and images from `show_image` appear below their tool call. Click a preview to open the image in your default app.
  - Tool calls the previous client showed generically now have titles: scratchpad, interaction, image, subagent, MCP, and plugin tools.
  - Markdown tables scroll sideways instead of squeezing their columns to fit.
  - A plugin message that fits on one line no longer shows an expand toggle.
  - Clicking the context usage in the header opens session diagnostics.
  - When a model or plugin request is waiting for you, Kit rings the bell, and sends a desktop notification if the terminal isn't focused.
- `147ed917` — feat(cli): select words and lines in the composer with double and triple clicks
  - A double-click selects a word, and a triple-click selects the whole line, including where it wraps. Typing replaces the selection. The scratchpad and annotation editors work the same way.
- `f4a7e51b` — feat(github): inform sessions of pull request status (#67)
- `119e2b2c` — feat(compaction): support dedicated model setting
- `c71a88aa` — feat(droids): cache refreshed model catalogs
- `85585c64` — fix: propagate diff timeouts and declared diff errors to clients (#72)
- `b93bb5ab` — fix(workingdiff): diff committed trees with one git process (#71)
- `dc8ea7fa` — fix(protocol): align stable protocol 45 compatibility

## Compatibility and limitations

The session protocol is still 45, and Kit's stored data format is unchanged. Stable 0.42.0-or-later releases that use protocol 45 may share a daemon, so a running 0.42.0 daemon keeps serving 0.43.0 clients until it is restarted. Development builds and release candidates are outside that compatibility promise.

Known differences from the previous terminal client:

- Centered content of odd width can sit one cell to the right.
- The signed-out **Connect a provider** button uses the accent color.
- `kit sessions` lists sessions before its picker opens and sizes the picker to them once.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
