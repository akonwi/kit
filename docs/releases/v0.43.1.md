# Kit 0.43.1

This patch fixes `kit new` and `kit --temp`, which failed to start in 0.43.0, and several conditions in the terminal client that did not do what they said. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `2790091f` — fix(cli): bind each `not` to the condition it negates (#79)
  - `kit new` and `kit --temp` start again. In 0.43.0 they stopped at "Kit could not start — create session returned a different session id", after the server had already created the session.
  - Pressing Enter on an empty API-key field no longer submits it or cancels a login in progress.
  - A session can't be renamed while its deletion is pending, and `/fork` does nothing while a reload is pending.
  - The Scratchpad is no longer fetched again once loaded, and unchanged Scratchpad text is no longer saved.
  - The Diff pane no longer starts watching before it has a workspace.
- `d6068c57` — refactor: remove the vaxis terminal client (#76)

## Compatibility and limitations

The session protocol is still 45, and Kit's stored data format is unchanged. Stable 0.42.0-or-later releases that use protocol 45 may share a daemon, so a running 0.42.0 or 0.43.0 daemon keeps serving 0.43.1 clients until it is restarted. Development builds and release candidates are outside that compatibility promise.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
