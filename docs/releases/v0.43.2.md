# Kit 0.43.2

This patch steadies tool-call chips in the terminal client while a turn runs, repaints a terminal tab when it becomes visible again, and adds Ruby syntax highlighting. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `b1dacb95` — fix(tui): keep the latest tool run open between calls
  - The latest run of tool calls in a turn now stays open through its fifth call while the turn works, instead of closing between calls and reopening when the next one starts. Fast calls no longer leave the run collapsed, and slower ones no longer flash it open and shut.
  - A run with six or more calls stays collapsed and keeps its spinner until the turn settles or prose follows it. A chip you open or close yourself keeps your choice.
- `166fd35b` — fix(tui): repaint when a hidden terminal tab becomes visible
- `9a39e636` — fix(tui): use normal text color for interaction dock body
- `fe8fb220` — feat(highlight): add Ruby syntax highlighting
  - Code blocks labeled `ruby` or `rb`, and `.rb`, `.rake`, and `.gemspec` files, are highlighted. Files recognized only by name, such as `Gemfile` and `Rakefile`, stay plain.
- `6a41924b` — refactor(cli): measure text with Cooper's graphemes (#80)

## Compatibility and limitations

The session protocol is still 45, and Kit's stored data format is unchanged. Stable 0.42.0-or-later releases that use protocol 45 may share a daemon, so a running 0.42.x or 0.43.x daemon keeps serving 0.43.2 clients until it is restarted. Development builds and release candidates are outside that compatibility promise.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
