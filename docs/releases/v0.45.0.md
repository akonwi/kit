# Kit 0.45.0

The terminal client now draws Mermaid sequence diagrams and flowcharts inline in the transcript. `kit attach` connects the terminal client to another Kit home's server without starting or replacing it. The daemon can also listen on a fixed address. This release moves the session protocol from 45 to 46, so it doesn't work with a running 0.44.x daemon or with the published macOS app; see the upgrade guide. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `7c16c693` — feat(tui): draw Mermaid sequence diagrams and flowcharts (#189)
  - Closed `mermaid` code fences in the transcript are drawn with Kit's theme colors instead of shown as source. A fence that is still streaming stays as source until it closes.
  - Sequence diagrams support participants, actors, messages, notes, frames such as `loop`, `alt`, `opt`, and `par`, `autonumber`, and titles. Activations and `rect` highlights are accepted but not drawn.
  - Flowcharts can go in any direction (`TD`, `TB`, `BT`, `LR`, `RL`). They support box, round, stadium, circle, database, and decision shapes; solid, dotted, and thick links with labels and arrowheads; loops; and subgraphs, each drawn as its own section below the diagram.
  - Other diagram types, malformed input, and diagrams over the size limits show their source with the reason. Styling lines (`classDef`, `class`, `style`, `linkStyle`, `click`) are accepted but not drawn. See `docs/features/mermaid.md`.
- `cd07433e` — Remote access phase 0: server identity, listen address, attach-only connectors, `kit attach` (#188)
  - `kit attach [SERVER]` runs the terminal client against another server, given by saved name, Kit home path, or `local`. Without a server, it shows a picker. Attaching never starts, stops, or replaces a server. It follows the server across restarts and refuses to talk to a different server that appears at the same home. The footer names the attached server. See `docs/features/attach.md`.
  - `kit servers [list|add|remove]` manages saved servers in `$KIT_HOME/servers.json`, which holds no secrets.
  - The `server.listen` setting and `kit server start|restart --listen <host:port>` give the daemon a fixed address. Loopback is the default, and any address beyond loopback must be set explicitly. See `docs/features/server-listen.md`.
  - The daemon now rejects requests whose `Host` header doesn't name it (status 421) and browser requests from unknown origins (status 403). Loopback addresses are always allowed. Add tunnel or proxy names to `server.allowedHosts` and `server.allowedOrigins`.
  - Health reports the server's `serverId`, a hashed `machineId`, and its `home`.
- `fac8e527` — fix(diff): bound observations by changed paths (#172)
  - The working-tree diff's 4,000-path limit now counts changed paths rather than every path in the repository. Large repositories no longer hide later changes, including newly untracked files.

## Upgrade guide

Kit 0.45.0 moves the session API from protocol 45 to protocol 46. Protocol-45 clients and daemons, including Kit 0.42.0 through 0.44.x and the published macOS app 0.1.3, can't connect to a 0.45.0 daemon. A 0.45.0 client refuses a running protocol-45 daemon and won't replace it on its own. Let active work settle, upgrade Kit, and then restart the daemon:

```sh
brew update && brew upgrade akonwi/tap/kit
kit server restart
kit version
kit server status
```

Update every attached CLI or Go client to a protocol-46 version. The public Go client (`github.com/akonwi/kit/api`) changes as follows:

- `AccessToken(token, instanceID)` is now `AccessToken(token)`. Drop the instance ID argument: an `Endpoint` target learns the running server instance itself, follows it across restarts, and returns `ErrServerChanged` if a different server answers.
- `Home(path)` is a new target for the daemon registered under another Kit home. Like other targets, it never starts, replaces, or stops that daemon.
- `Client.Server(ctx)` returns the connected server's identity (`ServerInfo`).

For manual installation, download `kit_v0.45.0_<platform>.tar.gz`, extract its single `kit` executable onto PATH, and verify `kit version`. Back up state before operational changes and don't try to downgrade the database.

## Compatibility and limitations

Any build on protocol 46 can attach to a 0.45.0 daemon. The published macOS app (0.1.3) uses protocol 45 and can't connect to this daemon until an updated app is released.

Listening beyond loopback doesn't make Kit usable remotely by itself. Kit doesn't terminate TLS, and remote clients need the daemon's credentials. Connecting over SSH and the network is planned under ADR 0045. `kit attach` currently reaches servers by Kit home on the same machine.

Mermaid diagrams are drawn only in the terminal client. Flowcharts are limited to 60 nodes, 120 edges, 200 statements, and 20 subgraphs, and drawings are limited to 480 columns by 800 rows. Node and edge styling, other node shapes and link kinds, and other diagram types aren't drawn yet.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
