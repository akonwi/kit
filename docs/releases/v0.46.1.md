# Kit 0.46.1

This patch shows Kit's session title in iTerm2 tabs. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `7f085940` — build(cli): update cooper for iTerm2 tab titles
  - Kit now sets the terminal title with OSC 0 instead of OSC 2. iTerm2 labels tabs with the icon name, which OSC 2 doesn't set, so the title (`kit - <session> - <directory>`, with its running marker) only reached the window title there. It now labels the tab too. Terminals with a single title, such as Ghostty, Kitty, WezTerm, Terminal.app, and tmux, behave as before.
  - If an iTerm2 tab still doesn't change, check that **Settings → Profiles → General → Title → Applications in terminal may change the title** is enabled.

## Compatibility and limitations

The session protocol is still 47, and Kit's stored data format is unchanged, so a running 0.46.0 daemon keeps serving 0.46.1 clients until it is restarted. The published macOS app (0.1.3) uses protocol 45 and can't connect until an updated app is released.

macOS CLI archives require macOS 14 or newer. Linux archives use Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
