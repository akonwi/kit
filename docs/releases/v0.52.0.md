# Kit 0.52.0

The terminal client draws data figures and callouts from fenced Markdown: twelve figure kinds, from a single stat to bars, timelines, decisions, and before-and-after deltas, plus GitHub-style `> [!NOTE]` callouts. Models learn the figure grammar from a new built-in `kit-figures` skill, which they load only when they're about to draw one. ```` ```diff ```` and ```` ```patch ```` fences now read as diff rows, like a diff in tool output. The session protocol stays 50, so this release works with Kit 0.51.0 clients and servers and with Kit for macOS 0.8.0; restart the server to give models the new skill. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `e291dbef` — feat(markdown): draw data figures and callouts
  - A fenced code block named after a figure kind, with `key="value"` attributes, is drawn as that figure: `stat`, `bars`, `meter`, `timeline`, `steps`, `decision`, `delta`, `spec`, `tree`, `compare`, `score`, and `stack`. Values are shown exactly as written and used only for scale; a figure shows a computed value only when an attribute asks for it, such as `delta`'s `change="percent"`, or its grammar defines one, such as `stack`'s row totals. See [ADR 0054](https://github.com/akonwi/kit/blob/main/docs/adrs/0054-draw-data-figures-from-fenced-markdown.md) and the grammar in [Figures](https://github.com/akonwi/kit/blob/main/docs/figures.md).
  - A figure that doesn't parse shows its source with a one-line reason, as a Mermaid diagram does. While a reply streams, a figure shows its source until its fence closes.
  - Quotes that start with `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, or `[!CAUTION]`, with an optional title after the marker, are drawn as callouts. Other quotes are unchanged.
  - Every session's skill catalog lists a new built-in skill, `kit-figures`, that teaches the figure and callout grammar. The core system prompt doesn't describe figures, so a session pays for the grammar only when the model activates the skill. Like `kit-customization`, `kit-figures` is reserved: a user or project skill with that name is omitted with a `skills.reserved_name` diagnostic.
  - Built-in skills are now stored as `SKILL.md` files with YAML frontmatter, the same format as user and project skills, so activating `kit-customization` returns its frontmatter followed by the same instructions.
- `2cfa5c56` — feat(markdown): draw diff fences as diff rows
  - ```` ```diff ```` and ```` ```patch ```` fences use the rows tool output gives a unified diff: muted hunks, changed lines on the diff fills, and the marker in its own lane. Lines before any file header are changes, so a snippet without headers reads as one. Long lines wrap under their text, and rows draw while the fence streams.
  - In tool output, a file header now ends at its `+++` line, so a header without a hunk no longer swallows the lines after it.
- `a8a38ed7` and `c712acad`, plus the macOS parts of the commits above, are macOS app changes. They ship in the macOS app's own release, not in this CLI.

## Compatibility and limitations

The session protocol stays 50, and the API, plugin protocol, and `droids` SDK don't change. Kit 0.52.0 clients and servers work with Kit 0.51.0 clients and servers, and with Kit for macOS 0.8.0 and newer. No upgrade steps are needed beyond the usual `kit update` (or `brew upgrade akonwi/tap/kit`) and a server restart; this release adds no database migration.

The `kit-figures` skill comes from the server, so models learn the figure grammar only after the server restarts on 0.52.0. Clients that don't draw figures, such as Kit 0.51.0 or Kit for macOS 0.8.0 attached to a 0.52.0 server, show a figure's fence as an ordinary code block and a callout as a quote with its `[!NOTE]` marker. Kit for macOS draws figures, callouts, and diff fences from its 0.9.0 release. The limit of 128 skills per session now counts both built-in skills, leaving room for 126 user and project skills.

Known issues: dismissing a subagent just as it finishes can leave its stored conversation until the server restarts ([#258](https://github.com/akonwi/kit/issues/258)). `kit update` treats `/dev/null` as a terminal and exits 0 instead of 2 ([#272](https://github.com/akonwi/kit/issues/272)). If one `kit update` has been downloading for over an hour, another `kit update` run in the same directory can remove its staged download ([#226](https://github.com/akonwi/kit/issues/226)). The terminal client can still panic while opening a session, in the background syntax highlighter ([#210](https://github.com/akonwi/kit/issues/210)). Subagent live streams still drop single events over 16 KiB until the subagent's transcript reloads ([#209](https://github.com/akonwi/kit/issues/209)), and one invalid event still fails every page of a subagent's live stream that holds it ([#208](https://github.com/akonwi/kit/issues/208)). Turn-end events still carry a generic failure reason for failures other than compaction ([#240](https://github.com/akonwi/kit/issues/240)).

macOS CLI archives require macOS 14 or newer. Linux archives are built on Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
