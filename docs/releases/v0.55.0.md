# Kit 0.55.0

Kit draws task lists. A `checklist` figure shows tasks done in any order, with `[ ]` and `[x]` boxes, one level of subtasks, and the task in hand in bold. The terminal client draws it, and the server's built-in `kit-figures` skill now teaches models to write it. The server's diff service also stops using a temporary directory altogether. The session protocol stays 50, so this release works with Kit 0.51.0 and newer clients and servers and with Kit for macOS 0.8.0 and newer; restart the server to get the server-side changes. The native macOS app is released separately and is not included in CLI archives.

## What's changed

- `d6bd31e8` — feat(figures): draw task lists as a checklist figure
  - A ` ```checklist ` fence holds 1–20 tasks, subtasks included. Each is `[ ] title` (open) or `[x] title` (done; `[X]` also works) with an optional note and indented body, and `- ` and `1. ` items both work. Tasks are done in any order and aren't numbered.
  - A task can have one level of subtasks, indented alike under it after its body. A subtask has a box and an optional note but no body. A task's box is what's written: Kit doesn't check a task when its subtasks are done.
  - Bold marks the task in hand (zero or one, never checked), and italic tasks recede. The terminal client draws a done task as a muted `✓` and an open one as `□`, in the accent color when it's in hand.
  - A `steps` figure whose items start with a box isn't drawn, and its reason now points to `checklist`. Other figures are unchanged.
  - The server's built-in `kit-figures` skill describes `checklist` and tells models to use it, not `steps`, for task lists. See [Figures](https://github.com/akonwi/kit/blob/main/docs/figures.md).
- `b2f7cfe7` — fix(workingdiff): run git without a temporary home
  - The server's diff service no longer creates a `kit-diff-git-*` directory at all. It runs git with `HOME` and `XDG_CONFIG_HOME` set to `/dev/null`, so user-level git config, attributes, ignore rules and credentials are still never read, and it pins `core.attributesFile` and `core.excludesFile` to `/dev/null` on every git command. Directories that releases before 0.54.0 left behind aren't removed; you can delete them from `$TMPDIR`.

The source tree's native iOS client (`apps/ios`) also gained features in this period. It isn't part of this release.

## Compatibility and limitations

The session protocol stays 50, and the session API and plugin protocol don't change. Kit 0.55.0 clients and servers work with Kit 0.51.0 and newer clients and servers, and with Kit for macOS 0.8.0 and newer. No upgrade steps are needed beyond the usual `kit update` (or `brew upgrade akonwi/tap/kit`) and a server restart; this release adds no database migration.

The skill change and the diff-service change run in the server, so they apply only after the server restarts on 0.55.0. Drawing a checklist is up to each client: the terminal client draws it from 0.55.0 and Kit for macOS from 0.11.0. Older clients don't know the `checklist` name and show the fence as an ordinary code block, which a 0.55.0 server's models are now more likely to write.

Known issues: dismissing a subagent just as it finishes can leave its stored conversation until the server restarts ([#258](https://github.com/akonwi/kit/issues/258)). `kit update` treats `/dev/null` as a terminal and exits 0 instead of 2 ([#272](https://github.com/akonwi/kit/issues/272)). If one `kit update` has been downloading for over an hour, another `kit update` run in the same directory can remove its staged download ([#226](https://github.com/akonwi/kit/issues/226)). The terminal client can still panic while opening a session, in the background syntax highlighter ([#210](https://github.com/akonwi/kit/issues/210)). Subagent live streams still drop single events over 16 KiB until the subagent's transcript reloads ([#209](https://github.com/akonwi/kit/issues/209)), and one invalid event still fails every page of a subagent's live stream that holds it ([#208](https://github.com/akonwi/kit/issues/208)). Turn-end events still carry a generic failure reason for failures other than compaction ([#240](https://github.com/akonwi/kit/issues/240)).

macOS CLI archives require macOS 14 or newer. Linux archives are built on Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
