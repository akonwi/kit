# Kit 0.60.0

Version 2 plugins can now see their session's status (model, thinking level, parent session, context use, and cumulative usage and cost) and learn when the session compacts its conversation. These are additions within plugin protocol version 2, so existing plugins keep working unchanged. The agent is now asked to write web addresses and file paths as Markdown links, and stat figures accept longer values. The session protocol stays 50, so this release works with Kit 0.51.0 and newer clients and servers and with Kit for macOS 0.8.0 and newer. The native macOS app is released separately and is not included in CLI archives.

## For plugin authors

**Nothing breaks in this release.** Every plugin that works with Kit 0.59.0 loads and runs the same way in 0.60.0, and plugin protocol version 1 still loads with its warning. What's new applies to plugins that speak version 2 ([ADR 0066](https://github.com/akonwi/kit/blob/main/docs/adrs/0066-share-session-status-with-plugins.md), [specification](https://github.com/akonwi/kit/blob/v0.60.0/docs/plugin-protocol/v2.md#session-status)):

- `initialize` params carry an optional `status` with the session's status when the instance starts: `sessionId`, `model`, `thinkingLevel`, `parent`, `context` (`tokens` and `window`, or null before Kit knows the window), and `usage` (the session API's cumulative usage and cost in US dollars, for this session only).
- Kit sends `kit/events/session.status.changed` with the full status when any member changes. Notifications are coalesced: a plugin always ends with the current status but may not see every intermediate one.
- The request `kit/session/status` takes no params and returns the latest status.
- Kit sends `kit/events/compaction.started` (`sessionId`, `compactionId`, `turnId`) and `kit/events/compaction.completed` (the same and `failureReason`). Like turn events they are best effort, so a start is not always followed by a completion.

A plugin that uses these on Kit 0.59.0 gets no `status` in `initialize`, no new notifications, and `-32601` from `kit/session/status`.

The TypeScript helper [`sdk/plugin/kit-plugin.ts`](https://github.com/akonwi/kit/blob/v0.60.0/sdk/plugin/kit-plugin.ts) adds `kit.session.status` (the latest status, or null when Kit sent none), `kit.session.getStatus()`, and the `session.status.changed`, `compaction.started`, and `compaction.completed` events; its in-memory Kit in `kit-plugin-testing.ts` serves them. Copy both files from the `v0.60.0` tag; a copy's `KIT_RELEASE` is `"0.60.0"`.

## What's changed

- `e53c53f3` — feat(plugins): share session status and compaction with plugins
- `3db65c0c` — feat(plugins): port the speech example to protocol version 2
  - Every example plugin in this repository's `.kit/plugins` now speaks version 2.
- `c74d96a5` — feat(prompt): ask the model to write URLs and file paths as Markdown links
  - Files use their path, relative to the working directory when inside it, as both text and target, so clients can open them.
- `d634ed17` — fix(figures): draw a long stat value small instead of failing the figure
  - A stat value of up to 16 characters (was 12) is drawn large. A longer value is drawn at the label's size instead of failing the figure, in the terminal and the browser client. A longer value with an arrow is a before and after, so the figure still isn't drawn and the reason points to a `delta` figure.
- `3896e4bf` — docs(skills): steer before-and-after values from stat to delta
  - The built-in kit-figures skill tells the agent to draw before-and-after values as a `delta` figure.

The source tree's macOS app also changed in this period. It isn't part of this release.

## Compatibility and limitations

The session protocol stays 50, and the session API is unchanged. Kit 0.60.0 clients and servers work with Kit 0.51.0 and newer clients and servers, and with Kit for macOS 0.8.0 and newer. No upgrade steps are needed beyond the usual `kit update` (or `brew upgrade akonwi/tap/kit`). Plugins and the system prompt run in the server, so restart it to give plugins session status and to use the new prompt. This release adds no database migration.

Plugin protocol version 1 still works in this release and is planned to be removed in a later one. Session status and compaction events are sent only to version 2 plugins. The TypeScript helper needs Bun, or Node 22.6 or newer with type stripping, wherever the plugin runs; Kit itself doesn't need either.

Known issues: plugin command failures don't say why ([#241](https://github.com/akonwi/kit/issues/241)). Dismissing a subagent just as it finishes can leave its stored conversation until the server restarts ([#258](https://github.com/akonwi/kit/issues/258)). `kit update` treats `/dev/null` as a terminal and exits 0 instead of 2 ([#272](https://github.com/akonwi/kit/issues/272)). If one `kit update` has been downloading for over an hour, another `kit update` run in the same directory can remove its staged download ([#226](https://github.com/akonwi/kit/issues/226)). The terminal client can still panic while opening a session, in the background syntax highlighter ([#210](https://github.com/akonwi/kit/issues/210)). Subagent live streams still drop single events over 16 KiB until the subagent's transcript reloads ([#209](https://github.com/akonwi/kit/issues/209)), and one invalid event still fails every page of a subagent's live stream that holds it ([#208](https://github.com/akonwi/kit/issues/208)). Turn-end events still carry a generic failure reason for failures other than compaction ([#240](https://github.com/akonwi/kit/issues/240)). Working-tree line comments go stale when any other file changes ([#286](https://github.com/akonwi/kit/issues/286)). `kit server pair` lists the addresses from the server's settings rather than the ones it serves ([#222](https://github.com/akonwi/kit/issues/222)). The browser client does not work offline.

macOS CLI archives require macOS 14 or newer. Linux archives are built on Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
