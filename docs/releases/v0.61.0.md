# Kit 0.61.0

Claude Fable 5.2 now works with a Claude subscription. Kit's subscription requests identified as Claude Code 2.1.280, and Anthropic rejects Fable 5.2 for Claude Code versions older than 2.1.290; they now identify as Claude Code 2.1.322. The terminal client can also show a workspace view (Diff, File, Subagent, Scratchpad) as its own client of a session, and inside [Rex](https://www.superlogical.com/rex/docs) it opens those views in Rex panes. The session protocol stays 50, so this release works with Kit 0.51.0 and newer clients and servers and with Kit for macOS 0.8.0 and newer. The native macOS app is released separately and is not included in CLI archives.

## Claude Fable 5.2 with a subscription

Requests signed in with a Claude subscription identify as Claude Code. With Kit 0.60.0 and earlier, choosing Claude Fable 5.2 failed with HTTP 400: "Claude Code 2.1.280 does not support this model; version 2.1.290 or newer is required." Kit 0.61.0 identifies as Claude Code 2.1.322 and sends nothing else differently.

If Anthropic rejects the Claude Code version for a later model, the error now says to update Kit, instead of Anthropic's advice to run `claude update`, which doesn't apply to Kit.

Claude Fable 5.2, Claude Opus 5, Claude Sonnet 5.5, and Claude Haiku 5.5 now get the same effort configuration as Claude Fable 5.1 and Claude Opus 5.5 (adaptive thinking at a steady high effort across the conversation), with a subscription or an API key.

Models run in the server: restart it on 0.61.0 for the fix to take effect.

## Workspace views in panes

`kit --session ID --view KIND` shows one workspace view of a session (`diff`, `file`, `host-file`, `subagent`, or `scratchpad`) with the session's header and footer and no transcript or composer; `kit attach SERVER --session ID --view KIND` does the same for a session on another server. Any multiplexer can arrange these clients beside `kit`. A single view never starts a server, never reports the session's status to the terminal, and never interrupts a run. See [workspace views in panes](https://github.com/akonwi/kit/blob/v0.61.0/docs/features/workspace-views.md) and [ADR 0067](https://github.com/akonwi/kit/blob/main/docs/adrs/0067-place-workspace-views-in-rex-panes.md).

When `kit` runs directly in a Rex terminal, opening a workspace view now opens it in a Rex pane by default: the first to the right of Kit, later ones stacked below it. Opening a view that is already open focuses its pane, and quitting Kit closes the panes it opened. Kit uses the `rex` tool that ships with the Rex server and needs Rex API revision 12 or later; if a pane can't be opened, Kit shows one warning and keeps views as tabs. To keep views as tabs in Rex, set `"workspacePanes": "tabs"` in `$KIT_HOME/settings.json`. Outside Rex, and in tmux running inside Rex, views stay tabs as before.

## Compatibility and limitations

The session protocol stays 50, and the session API is unchanged. Kit 0.61.0 clients and servers work with Kit 0.51.0 and newer clients and servers, and with Kit for macOS 0.8.0 and newer. No upgrade steps are needed beyond the usual `kit update` (or `brew upgrade akonwi/tap/kit`), then restarting the server so Claude Fable 5.2 works with a subscription. This release adds no database migration and doesn't change the plugin protocol.

Rex is in preview, and pane placement was checked against Rex 0.1.0-preview.14 (API revision 12).

Known issues: plugin command failures don't say why ([#241](https://github.com/akonwi/kit/issues/241)). Dismissing a subagent just as it finishes can leave its stored conversation until the server restarts ([#258](https://github.com/akonwi/kit/issues/258)). `kit update` treats `/dev/null` as a terminal and exits 0 instead of 2 ([#272](https://github.com/akonwi/kit/issues/272)). If one `kit update` has been downloading for over an hour, another `kit update` run in the same directory can remove its staged download ([#226](https://github.com/akonwi/kit/issues/226)). The terminal client can still panic while opening a session, in the background syntax highlighter ([#210](https://github.com/akonwi/kit/issues/210)). Subagent live streams still drop single events over 16 KiB until the subagent's transcript reloads ([#209](https://github.com/akonwi/kit/issues/209)), and one invalid event still fails every page of a subagent's live stream that holds it ([#208](https://github.com/akonwi/kit/issues/208)). Turn-end events still carry a generic failure reason for failures other than compaction ([#240](https://github.com/akonwi/kit/issues/240)). Working-tree line comments go stale when any other file changes ([#286](https://github.com/akonwi/kit/issues/286)). `kit server pair` lists the addresses from the server's settings rather than the ones it serves ([#222](https://github.com/akonwi/kit/issues/222)). The browser client does not work offline.

macOS CLI archives require macOS 14 or newer. Linux archives are built on Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
