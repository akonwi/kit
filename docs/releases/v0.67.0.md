# Kit 0.67.0

Sessions now keep working when their folder is deleted, such as a worktree removed after its work merged; before, they failed to open once the server restarted. A new built-in `kit-browser` skill helps the model use the Mac app's in-app browser. The server no longer answers the old bounded file reads, so Kit for macOS 0.20.x and older and older iOS TestFlight builds can't show files against it; see [Compatibility](#compatibility-and-limitations). The session protocol stays at 51. Kit for macOS 0.22.0 and a new iOS TestFlight build ship alongside this release. The native macOS app is released separately and is not included in CLI archives.

## Sessions without their folder

A session whose working directory is deleted, moved, or unmounted now opens and keeps working ([ADR 0075](https://github.com/akonwi/kit/blob/v0.67.0/docs/adrs/0075-keep-sessions-usable-without-their-working-directory.md)). Its transcript, scratchpad, subagents, and settings are all there, and the model can keep working:

- Only your user-level `AGENTS.md`, skills, prompt commands, agents, and MCP servers load. Project skills, context, and prompt commands are skipped while the folder is missing.
- Shell commands and tools given relative paths fail on each call with `the working directory <path> does not exist` and suggest changing it, instead of a confusing missing-file or launch error. Absolute paths still work.
- Writes and saved attachments to a relative path are refused, so the deleted folder isn't recreated.
- MCP stdio servers without a configured `cwd` start in your home folder.
- `/cd` or `change_cwd` to an existing folder moves the session and reloads its project context, skills, and prompt commands from there. If the folder comes back, `/cd` to it or `/reload` picks its project configuration up again.

## The kit-browser skill

Kit now has a built-in `kit-browser` skill with guidance for the Mac app's in-app browser: when to use it instead of fetching a page, the snapshot-then-act loop, screenshots, your tabs and sign-ins, untrusted pages, downloads, and showing you what it did. It's offered only while the Mac app's browser tools are connected to the session, appearing and disappearing with them without a reload, and subagents that receive the browser tools get it too. A user or project skill named `kit-browser` replaces it.

## Old file reads removed

The server no longer answers the bounded file reads (`readWorkspaceFile` and `readHostFile`) that 0.66.0 deprecated. Every current client downloads whole files instead. Fixes [#298](https://github.com/akonwi/kit/issues/298).

## Compatibility and limitations

The session protocol stays at 51, and there is no database migration. The OpenAPI compatibility check against 0.66.0 reports no breaking changes. To pick up the new server, upgrade and restart it (`kit update`, or `brew update && brew upgrade akonwi/tap/kit` then `kit server restart`), and reload open browser tabs.

**Update your Apple apps.** Against this server, Kit for macOS 0.20.x and older, and iOS TestFlight builds up to 20261122.1930, can't show files: workspace files say "This file no longer exists." and host files say the server is too old. Sessions and everything else still work with them. Update the Mac app to 0.21.0 or later (0.22.0 ships alongside this release), and the iOS app to the new TestFlight build.

**Plugin authors:** the plugin protocol doesn't change. The TypeScript helper's `KIT_RELEASE` is `"0.67.0"`.

Known issues: the terminal client shows at most 2 MiB and 65,536 lines of a file ([#294](https://github.com/akonwi/kit/issues/294)). Plugin command failures don't say why ([#241](https://github.com/akonwi/kit/issues/241)). Dismissing a subagent just as it finishes can leave its stored conversation until the server restarts ([#258](https://github.com/akonwi/kit/issues/258)). `kit update` treats `/dev/null` as a terminal and exits 0 instead of 2 ([#272](https://github.com/akonwi/kit/issues/272)). If one `kit update` has been downloading for over an hour, another `kit update` run in the same directory can remove its staged download ([#226](https://github.com/akonwi/kit/issues/226)). The terminal client can still panic while opening a session, in the background syntax highlighter ([#210](https://github.com/akonwi/kit/issues/210)). Subagent live streams still drop single events over 16 KiB until the subagent's transcript reloads ([#209](https://github.com/akonwi/kit/issues/209)), and one invalid event still fails every page of a subagent's live stream that holds it ([#208](https://github.com/akonwi/kit/issues/208)). Turn-end events still carry a generic failure reason for failures other than compaction ([#240](https://github.com/akonwi/kit/issues/240)). Diff file summaries never carry line counts ([#285](https://github.com/akonwi/kit/issues/285)). `kit server pair` lists the addresses from the server's settings rather than the ones it serves ([#222](https://github.com/akonwi/kit/issues/222)). The browser client does not work offline.

macOS CLI archives require macOS 14 or newer. Linux archives are built on Ubuntu 24.04 with a glibc 2.39 baseline and are not fully static. Windows and npm distribution are unsupported.
